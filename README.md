# 🚗 DriveNow - Vehicle Rental Management System

## 📌 Project Description
DriveNow is a MERN stack-based vehicle rental system where users can easily rent vehicles, and administrators can efficiently manage vehicle listings, bookings, and user data.

---

## 🛠 Tech Stack
* **Frontend:** React (Vite), Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JSON Web Tokens (JWT)

---

## 🚀 Features
* User Registration & Secure Login
* JWT-based Authentication & Route Protection
* Browse and Filter Vehicle Listings
* Real-time Vehicle Booking System
* Admin Dashboard for Inventory Management
* Secure Payment Integration
